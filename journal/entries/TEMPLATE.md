Write the post here in plain text. The first paragraph is used as the
preview on the Journal index, so make it count.

Leave a blank line between paragraphs. You can write as many as you like.

To add a photo, drop the image file into this same folder
(journal/entries/) and reference it by filename:

![Short caption for the photo](my-photo.jpg)

That's it. You can use:

## A subheading

- a bullet
- another bullet

> a pulled-out quote

Optional front-matter fields (the bit between the --- lines at the top):
  title     — required, the headline
  date      — YYYY-MM-DD, controls the displayed date
  location  — shown in the metadata column
  tag       — e.g. Inspection / Field Note / Condition Report
  cover     — (optional) filename of the thumbnail to show on the index;
              if omitted, the first photo in the post is used
  excerpt   — (optional) custom preview text; if omitted, the first
              paragraph is used
